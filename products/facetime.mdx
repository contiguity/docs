    ## Dial

    ```javascript
    const call = await contiguity.facetime.dial({
        to: "+15125550100",
        from: "+18005551234",
        caller_id: "Tesla Support",
    });
    ```

    ## Answer, reject, hang up

    `get`, `answer`, `reject`, and `hangup` take a call ID, a parsed webhook event, or `event.data`.

    ```javascript
    const event = contiguity.webhook.parse(raw_body);

    if (event.type === "facetime.call.ringing" && event.data.direction === "inbound") {
        await contiguity.facetime.answer(event, { caller_id: "Support" });
    }

    await contiguity.facetime.reject(event);
    await contiguity.facetime.hangup(event);
    const call = await contiguity.facetime.get(event);
    ```

    ## Availability

    ```javascript
    const { available } = await contiguity.facetime.availability("+15125550100");
    ```
