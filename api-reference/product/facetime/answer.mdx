<Note>
    This endpoint is for inbound calls. Answering moves the call to `in_progress` and fires [`facetime.call.answered`](/api-reference/webhook/example-v2#facetime-call-answered).
</Note>

`caller_id` is optional. Use it to present a name on the call.
