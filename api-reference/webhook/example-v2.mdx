## Webhook Payload Format

All webhook notifications follow this consistent structure:

```json
{
  "id": "evt_d61aCHRo18",
  "type": "text.incoming.sms", 
  "timestamp": 1726502400,
  "api_version": "v2025.9.7",
  "data": {
    // event-specific data
  }
}
```

Contiguity sends many different event types to your webhook endpoint — see the full, organized list on the dedicated [**Webhook Events**](/api-reference/webhook/events) page, with on-page navigation to jump straight to any event.
